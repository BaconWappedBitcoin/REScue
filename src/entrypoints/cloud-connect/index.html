Sync across browsers

REScue will keep one small file with your settings (and your user tags, unless you turn that off) in the app folder of your own cloud storage. Every browser where you connect the same account gets the same settings.

The file goes only to your storage provider. REScue has no server and never sees it. Read history, saved comments and hidden posts are never sent.

Next, the browser asks you to let REScue talk to , then the provider asks you to sign in and allow access to that one folder.

You can disconnect at any time in REScue settings, under Sync.
